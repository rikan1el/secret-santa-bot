# Тайный Санта

Telegram-бот для игры «Тайный Санта» на 6 человек (3 пары).

Требуется Python 3.12+.

## Запуск

```bash
pip install -r requirements.txt
python bot.py
```

Перед запуском задайте в `config.py`:

- `BOT_TOKEN` — токен от @BotFather;
- `ADMIN_ID` — числовой Telegram ID администратора;
- `PAIRS` — три пары участников (username или числовой ID), партнёры никогда не дарят друг другу;
- `DEFAULT_GAME` — бюджет, даты и время по умолчанию (потом можно менять в панели);
- `TIMEZONE` — часовой пояс (по умолчанию `Europe/Moscow`).

Запускайте **только один экземпляр** бота: защита от одновременной записи работает внутри процесса.

## Порядок игры

1. Администратор добавляет бота в групповой чат и отправляет `/santa`.
2. Участники нажимают «Участвовать», затем пишут боту в личку `/profile` и заполняют анкету.
3. Администратор проверяет список и запускает жеребьёвку: `/draw` или `/admin` → «Жеребьёвка».
4. Каждый участник получает в личку анкету своего получателя, а в группе появляется
   пост «🎉 Жеребьёвка прошла, проверьте личку». Повторно — `/my`.
5. Отменить результат можно только явно: `/reset` (участники получат уведомление).

## Команды

| Команда | Кто | Назначение |
|---|---|---|
| `/santa` | админ, в группе | открыть регистрацию |
| `/start` | все | регистрация/статус в личке |
| `/profile` | участник | заполнить или изменить анкету до жеребьёвки |
| `/my` | участник | показать своего получателя |
| `/list` | админ | участники и статус |
| `/draw` | админ | провести жеребьёвку |
| `/reset` | админ | сбросить жеребьёвку |
| `/health` | админ | самопроверка данных и жеребьёвки |
| `/admin` | админ | панель с inline-кнопками |

В панели: настройка бюджета (минимум ≤ максимум), дат и времени, текст объявления,
рассылка объявлений участникам, управление парами и кнопка «Переотправить результаты».

## Приватность

Администратор **не видит**, кто кому дарит. Он получает только отчёт «доставлено X из Y»
и список участников, которым не удалось отправить личное сообщение (например, не нажали
«Старт»). Жеребьёвка при этом не перезапускается: участник может открыть личку бота
(нажать `/start`) и получить результат, а администратор — нажать «🔁 Переотправить
результаты» в панели или кнопку под отчётом.

## Оформление анкеты

Анкета приходит в HTML-разметке: заголовки, разделители, кликабельная ссылка на профиль
и автоматические ссылки на товары. Пользовательский ввод экранируется, поэтому `<`, `>`
и `&` в тексте ничего не ломают.

## Самопроверка

`/health` (админ) проверяет: читаемость JSON-файлов, уникальность участников,
существование обоих участников каждой пары, корректность жеребьёвки (все участники,
биекция, нет самоназначений и партнёров), бюджет и наличие недоставленных результатов.

## Логи

Бот пишет понятные логи, которые видно в `pm2 logs secret-santa`:

```
2026-11-10 12:00:01 | INFO    | Старт бота: админ=123, участников=6, жеребьёвка=нет, TZ=Europe/Moscow
2026-11-10 12:05:44 | INFO    | Зарегистрирован участник: Анна (id=101), всего 1/6
2026-11-10 12:10:00 | INFO    | Анкета сохранена: Анна (id=101)
2026-11-10 18:00:02 | INFO    | Жеребьёвка: старт, участников 6
2026-11-10 18:00:05 | INFO    | Жеребьёвка: результаты доставлены 6/6, ошибок 0
2026-11-10 18:00:05 | INFO    | Опубликован пост о жеребьёвке в чате -100123
2026-11-10 18:00:05 | INFO    | Напоминание 'exchange' отправлено: 6 из 6
```

Шумный лог aiogram (`Update id=... is handled`) понижен до предупреждений, чтобы
вывод был читаемым. Сообщения об ошибках доставки, неразрешённых парах и сбоях
публикации тоже попадают в лог.

Полезные команды:

```bash
pm2 logs secret-santa --lines 100     # последние строки
pm2 logs secret-santa                 # поток в реальном времени
pm2 logs secret-santa --err           # только stderr
```

## Важно про пары и время

- Перед жеребьёвкой бот проверяет, что **все пары указывают на реальных участников**.
  Если хотя бы один username/ID не найден, жеребьёвка отменяется с пояснением — иначе
  партнёры могли бы попасть друг к другу. Исправьте пары в `/admin → 💑 Пары`.
- Все даты и напоминания считаются в часовом поясе `TIMEZONE` из `config.py`, независимо
  от часового пояса сервера. Ставьте реальный пояс игры, иначе дедлайны сдвинутся.
- Формат дат — строго `ДД.ММ.ГГГГ` или `ДД.ММ.ГГГГ ЧЧ:ММ`. Некорректная строка просто
  отключает напоминание для этой даты (бот не упадёт, но и не напомнит).

## Напоминания

Планировщик APScheduler раз в час проверяет даты и отправляет:

- напоминание о дедлайне регистрации;
- напоминание о заполнении анкеты (только тем, у кого её нет);
- предупреждение о скорой жеребьёвке + сводку администратору о пропущенных анкетах;
- напоминание о дате обмена подарками («не забудьте подготовить подарок», за сутки до
  обмена, отправляется и после жеребьёвки);
- автозапуск жеребьёвки в назначенные дату/время (если регистрация открыта).

Каждое напоминание отправляется один раз и не повторяется после перезапуска.

## Данные

Файлы создаются рядом с `bot.py` при первом изменении:

- `participants.json` — участники, анкеты, черновики, пары;
- `assignments.json` — результат жеребьёвки;
- `settings.json` — настройки игры;
- `state.json` — статус игры;
- `reminders.json` — отправленные напоминания.

Запись атомарная (временный файл → `flush` + `fsync` → `os.replace`). Повреждённый JSON
переименовывается в `*.corrupt`, а бот продолжает с пустыми данными.
